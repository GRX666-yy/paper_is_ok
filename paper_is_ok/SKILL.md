# 论文查重技能（Paper Duplication Check）

驱动 agent 对用户的论文（.pdf / .tex）执行一套规范、可复现、可量化的查重流程：通读论文 → 检索近 15–20 年相关文献 → 逐句比对 → 计算加权查重率 → 生成带颜色标注的查重报告（有 LaTeX 环境:tex+pdf；无 LaTeX 环境:docx+pdf），统一放入 `查重报告\` 文件夹交付。

## 环境依赖

- Python ≥ 3.8，依赖 `pypdf`（PDF 解析用）与 `python-docx`（Word 报告输出用）：`pip install pypdf python-docx`
- PDF 报告二选一：①本机有 TeX（`xelatex` + `ctex` 宏包）→ 编译 tex；②无 LaTeX 环境 → 生成 Word 版（.docx）并经本机 Word/WPS/LibreOffice 自动转为 PDF
- 联网检索能力：使用当前环境中可用的网页搜索 / 网页读取工具（如 WebSearch / WebFetch），配合多平台学术检索（平台清单见 `references/search-sources.md`：arXiv、Semantic Scholar、OpenAlex、Crossref、ACL Anthology、CORE、Unpaywall、百度学术、IEEE/Springer/CNKI 等 A/B/C 三类）
- 本技能目录下的 `scripts/` 与 `references/` 必须随技能一起存在

## 核心概念（先读懂再动手）

### 疑似等级与权重

| 等级 | 权重 | 报告标记 | 一句话定义 |
|------|------|----------|-----------|
| 无疑似 | 0 | 不标记、不注释 | 表述原创或已充分改写 |
| 轻微疑似 | 0.2 | 黄色 | 观点/表述高度相近，连续重合 6–9 字符 |
| 中度疑似 | 0.3 | 橙色 | 句式结构保留仅换措辞，连续重合 10–17 字符 |
| 严重疑似 | 0.5 | 红色 | 连续重合 ≥18 字符，或整段仅作同义词替换 |

完整量化判定标准见 `references/rubric.md`，**标注时必须严格依据该标准并写明触发的条款编号**。

### 查重率公式

```
查重率% = Σ( 每个疑似片段的非空白字符数 × 该片段等级权重 ) ÷ 检测总字符数 × 100
```

示例：10000 字论文中一段 100 字被判定为严重疑似 → (100 × 0.5) ÷ 10000 × 100 = 0.5%。

### 检测字符口径（对照知网规则）

- **检测总字符数只统计正文**：目录、图表目录、参考文献、致谢、附录、作者声明等系统可识别部分**不参与比对、不计入总字符**（`generate_report.py` 按章节名自动排除）；
- 摘要、引言、研究方法、实验/数据分析、结论等正文核心**均参与**比对；
- **数学公式以其 LaTeX 源码完整保留并参与比对与字符统计**（按 R5 条款判级：实质抄袭判严重；标准公式且已规范引用不判级；标准公式未标注出处判轻微）；
- **规范格式的直接引用**（引号或 [1] 式编号）标注 `quote: true`，不计入查重率、单独计算"引用率"（对应知网"去除引用文献复制比"口径）；
- 知网实际连续匹配阈值约为 **13–15 字符**，与本技能的严重疑似阈值（18 字符）已较接近但仍略宽松，汇报时必须向用户说明本结果仍偏低。

### 检索范围

以**当前年份往前 15 年**为主区间（含当年），关键文献可放宽至**前 20 年**。早于 20 年的文献仅当论文直接引用且高度相关时才纳入。

## 工作流程（严格按阶段顺序执行）

### Phase 0 接收与校验文件

- 确认用户提供了 `.pdf` 或 `.tex` 文件，且路径存在。两者都没有时询问用户。
- 记录文件路径，创建工作目录 `paper_check_work/`（与论文同目录）。

### Phase 1 解析论文文本

```bash
python <skill目录>/scripts/extract_text.py "<论文文件路径>" -o paper_check_work/paper_blocks.json
```

- 读取脚本 stdout：块数量、总字符数、质量警告。
- **若出现"疑似扫描版/抽取质量差"警告，必须请求用户提供 .tex 源文件**，扫描版 PDF 无法可靠查重。
- 向用户报告：全文非空白字符数、章节数。

### Phase 2 通读论文

- 分块读取 `paper_blocks.json`（每次 ≤30 个 block，避免上下文超限），**通读全文**。
- 向用户简要复述：论文题目、主题、核心贡献、章节结构、关键词，确认理解无误后再继续。

### Phase 3 文献检索

两条种子线索并行展开：

1. **论文自身参考文献列表（最高优先级）**——与论文重叠概率最高，逐条核对相关性，凡近 20 年内且与论文主题相关的全部纳入比对池。
2. **关键词扩展检索**——用论文标题词、关键词列表、各章核心术语（中英文各构造 3–5 组查询），在多平台交叉查找**未被论文引用**的相关文献（用于发现未标注来源的重叠）。

**平台使用规则**（完整清单、接口地址与检索策略见 `references/search-sources.md`）：

- **A 类免费全文优先**：arXiv、OpenReview、ACL Anthology、PMLR、CORE、BASE、DOAJ、PubMed Central、Zenodo 等，能拿到全文的优先全文比对；
- **B 类元数据/引文图谱用于发现**：Semantic Scholar、OpenAlex、Crossref、dblp、Google Scholar（经网页搜索）、百度学术；用前向/向后滚雪球与相似推荐扩展；
- **C 类付费出版商**：IEEE Xplore、ACM、ScienceDirect、SpringerLink、Wiley、CNKI/万方/维普等，摘要可见；需要全文时**转入 Phase 4 付费询问流程**；
- 每篇文献按固定顺序尝试：A 类 OA 全文 → 作者主页/机构仓库 → Unpaywall（按 DOI 查合法 OA 版）→ C 类摘要 → Phase 4 询问；
- **禁止使用 Sci-Hub、LibGen 等盗版渠道**。

规则：

- 比对池按相关度排序，规模建议 15–40 篇，满足 `references/search-sources.md` 第 5 节的收敛条件即停止检索，不无限扩张。
- 逐篇获取全文文本，保存到 `paper_check_work/sources/01_标题简称.txt` 等文件；只能拿到摘要的，在标注中记 `access: "abstract"`（比对精度受限）。
- 检索结果与论文主题无关的直接丢弃。

### Phase 4 付费文献处理（必须逐条询问，不得擅自跳过）

当某篇需要比对的文章只有付费渠道可获取全文时：

1. **先询问用户**："文献《X》需要付费获取全文，您是否已付费/已拥有该资源？若有，请提供 PDF 或关键章节文本。"
2. 用户有资源 → 使用用户提供的文本，按全文比对处理。
3. 用户无资源：
   - 付费文献占应比对文献池 **≤ 1/3** → 跳过全文比对（可退而基于摘要做参考级比对），记入标注文件 `skipped` 字段；
   - **> 1/3** → 覆盖率不足，明确告知用户，由用户决定：A. 基于摘要继续（结果精度受限）B. 中止等用户补充资源 C. 换用替代文献。

### Phase 5 逐句比对与标注

- **比对范围**：摘要、引言、相关工作、研究方法、实验/数据分析、结论等正文核心内容。**目录、图表目录、参考文献列表、致谢、附录、作者声明、图表标题不参与比对，也不计入检测总字符数**（脚本会按章节名自动排除这些块并打印 INFO）；**数学公式以 LaTeX 源码保留在正文中，参与比对与字符统计**（按 R5 判级）。
- **比对单位**：以句子为主；整段连续复制时按整段标注一次。
- 将用户论文的每个句子/段落与比对池中各文献文本逐一对照，依据 `references/rubric.md` 判级：
  - 每条标注必须记录：来源文献（题名/作者/年份/出处/链接）、**来源文献中对应的原文片段**、判定理由（引用 rubric 条款编号）。
  - **规范直接引用**（引号或 [1] 式编号正确标注的）额外加 `"quote": true` 字段。
  - 无疑似的句子不打标（权重为 0，不进标注文件）。
- 输出到 `paper_check_work/annotations.json`（格式见 `references/data-formats.md`）。论文很长时按章节分多轮完成，每轮增量合并写盘，防止上下文超限。

### Phase 6 计算查重率并生成报告

```bash
python <skill目录>/scripts/generate_report.py paper_check_work/paper_blocks.json paper_check_work/annotations.json -o 查重报告.tex --compile
```

（支持多个标注文件依次传入自动合并；`--compile` 可选，会在本机有 xelatex 时编译出 `查重报告.pdf`。）

脚本自动完成：片段字符统计、加权查重率计算、生成报告。**查重率以脚本输出为准，不要手工心算。**

**交付方式（二选一，统一放入与论文同目录的 `查重报告\` 文件夹，文件名统一为 `查重报告.*`）**：

- **方式 A（本机有 LaTeX）**：`--compile` 编译 tex，交付 `查重报告\查重报告.tex` + `查重报告\查重报告.pdf`；
- **方式 B（无 LaTeX 环境或用户只提供 PDF/要求 Word）**：加 `--docx`，交付 `查重报告\查重报告.docx` + `查重报告\查重报告.pdf`（脚本依序经 MS Word COM → WPS COM → LibreOffice 自动转换；三者都不可用时只交付 docx，并告知用户"用 Word/WPS 打开后另存为 PDF"）；
- 注意：xelatex 对中文路径的命令行解析可能失败，此时把 tex 复制到纯英文路径编译再把 PDF 复制回 `查重报告\`。

**LaTeX 环境不完整时的交互规则（必须先询问用户，不得静默切换）**：

- 脚本输出 `LATEX_STATUS: missing-xelatex`（无 LaTeX）或 `LATEX_STATUS: compile-failed`（编译失败，可能附 `MISSING_PACKAGES: 缺失宏包列表`）时，**向用户询问**："您的 LaTeX 环境不完整（缺少：xx 宏包 / 未安装 TeX 发行版），是否愿意补全环境并安装缺失宏包？"
- **用户愿意** → 引导修复：MiKTeX 执行 `miktex packages install <包名>`，或重跑命令时加 `--enable-installer` 允许联网自动安装；TeX Live 执行 `tlmgr install <包名>`。装好后重新 `--compile`，继续方式 A；若修复后仍失败，再次询问（重试 / 转 Word）。
- **用户不愿意** → 转方式 B：加 `--docx` 生成 Word 版并转 PDF，交付 `查重报告\查重报告.docx + 查重报告.pdf`，不再交付编译失败的 tex。

报告内容要求（脚本已内置）：

- 结果摘要页：总查重率、公式、统计表、比对覆盖率；
- 疑似明细表：每条标注的等级、位置、论文片段、来源文献与原文片段、判定理由、对查重率的贡献；
- 未比对文献清单（付费跳过等）；
- **全文高亮重现**：轻微=黄色、中度=橙色、严重=红色，无疑似不着色；每处疑似带 `[编号]` 上标对应明细表。

编译失败时（缺 xelatex 等）：交付 `.tex` 文件并告知用户本地编译命令 `xelatex 查重报告.tex`（需 ctex 宏包）。

### Phase 7 结果汇报

向用户报告并附免责声明：

1. 总查重率（不计规范引用，精确到两位小数）、含引用的总复制比、引用率与各等级统计；
2. 重合最严重的 3–5 个问题区域（章节 + 来源文献）；
3. 比对覆盖率与跳过的付费文献清单；
4. 口径说明：目录/参考文献/致谢/附录已排除；知网实际阈值 13–15 字符严于本技能，本结果偏低仅供参考，不等同于知网/iThenticate 等官方查重报告；
5. **随附降重指南**：把 `references/reduce-duplication.md` 复制一份到用户论文同目录（如 `降重指南.md`），并提示用户按报告颜色优先级（红→橙→黄）对照指南逐条改写后复检。

## 硬性规则

- 付费文献必须先询问用户，未经询问不得跳过。
- 检索范围默认近 15 年、可放宽至 20 年，早于 20 年不予纳入。
- 每条疑似标注必须给出可核查的来源与理由，禁止无来源判级。
- 无疑似不打标、不上色、不计入查重率。
- 报告文件名固定为 `查重报告.tex`。
- 与用户沟通时使用用户的语言（默认中文）。
- 遵守版权：向用户展示来源文献时只引用比对所必需的短句（≤50 字/处），不整段复制他人论文。
